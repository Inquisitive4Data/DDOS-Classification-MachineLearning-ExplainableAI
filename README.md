# DDOS-Classification-MachineLearning-ExplainableAI
DDOS Classification for cybersecurity using Random Forest and LIME
This repository provides an implementation of a Distributed Denial of Service (DDoS) detection system using a Random Forest classifier. The model achieves high detection accuracy while incorporating Local Interpretable Model-agnostic Explanations (LIME) for enhanced interpretability. This study demonstrates how Explainable AI (XAI) can aid in understanding and mitigating network security threats effectively.

🌟 Key Highlights
Objective:

To classify network traffic into benign or DDoS categories with high accuracy.
To enhance model transparency and interpretability using LIME.
Performance Metrics:

Accuracy: 99.95%
Precision: 1.0000
Recall: 0.9990
F1 Score: 0.9995
Explainability:

LIME was used to identify the most influential features driving the classifier’s decisions.
Actionable insights were derived to improve model understanding and cybersecurity strategies.
📊 Methodology
Data:
A labeled dataset of benign and DDoS network traffic was used for training and testing.
Model:
Random Forest Classifier:
Robust ensemble-based algorithm known for its accuracy and scalability in classification tasks.
Explainability:
LIME:
Provides local explanations for model predictions by highlighting feature contributions for individual classifications.
